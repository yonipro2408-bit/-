# מה יש באזור? (אב-טיפוס חזית)

אב-טיפוס סטטי: דף גילוי, חיפוש טקסט, סינון לפי קטגוריה, מועדפים (נשמרים בדפדפן) ומסך מפה ריק.
**אין** בו עדיין מאגר נתונים, מפה, משתמשים או AI. כל המקומות הם נתוני הדגמה שנוצרים לפי העיר והקטגוריה. רשימת הערים היא רשימת שמות אמיתית. לוגו ואייקונים בתיקיית `assets/`.

## העלאה
1. צור repo חדש ב-GitHub והעלה את התיקייה.
2. ב-Netlify: Add new site, Import from Git, בחר את ה-repo. אין build command, ו-Publish directory הוא `.`

## מה חסר (ממתין להחלטות שלך)
מקורות נתונים, ספק מפות, מסד נתונים, התחברות, כשרות (רק ממקור מאומת), תקציב.
