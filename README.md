# מה יש באזור? (אב-טיפוס)

קובץ יחיד (`index.html`) עם הלוגו והאייקונים משובצים בתוכו. אין תיקיות להעלאה.
הנתונים אמיתיים וחיים מ-OpenStreetMap (Overpass + Nominatim), בחינם וללא מפתח. נדרשת הכרה במקור (מופיעה באפליקציה).

## העלאה
העלה ל-GitHub את `index.html`, `netlify.toml`, `README.md` ו-Netlify יעלה אוטומטית. אין build command.

## מגבלות ידועות
- שרתי OpenStreetMap הציבוריים מתאימים לאב-טיפוס ולא לעומס אמיתי. בהמשך נעבור למאגר משלנו.
- כשרות מוצגת רק היכן שסומנה ב-OSM (חלק קטן מהמקומות). לא ממציאים כשרות.
- אירועים, שעות פתיחה, תמונות וביקורות עדיין אין מקור נתונים.
